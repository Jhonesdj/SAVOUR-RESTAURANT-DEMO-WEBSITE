# SAVOUR — Restaurant Website Concept

A responsive restaurant website concept built as a web development portfolio project. SAVOUR is fictional; its contact details, address, menu, prices, opening hours, and delivery information are examples for demonstration only.

## Live Demo

[View the website](https://jhonesdj.github.io/SAVOUR-RESTAURANT-DEMO-WEBSITE/)

## Features

- Responsive restaurant landing page
- Hero, story, popular dishes, menu, gallery, location, and contact sections
- Menu filters for breakfast, lunch, and dinner
- Mobile navigation menu
- Reservation form that opens a prefilled WhatsApp message
- Keyboard-friendly navigation and form labels
- Reduced-motion support

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

1. Download or clone this project.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a browser.

No build tools or installation are required.

## Project Files

```text
index.html   Page structure and content
style.css    Layout, colors, and responsive styles
script.js    Menu filters, mobile navigation, and demo reservation behavior
README.md   Project overview and instructions
```

## Demo Reservation Behavior

Submitting the form opens WhatsApp with a prefilled message addressed to a demo number. It does not send a reservation, save form information, or confirm a booking. Replace the demo number with a real business number only if adapting the project for an actual restaurant.

## Portfolio Note

This is a fictional concept project and is not affiliated with a real restaurant. Photos are loaded from Unsplash and require an internet connection.
